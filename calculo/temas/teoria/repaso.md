### ¿Qué es una función?
Una **función** $f$ asigna a cada valor $x$ de su **dominio** un único valor $f(x)$.
Evaluar $f(3)$ es reemplazar cada $x$ por $3$ (¡con paréntesis si el número es negativo!).

### Herramientas de álgebra que vas a usar todo el curso
- **Factor común:** $ax + ay = a(x + y)$.
- **Diferencia de cuadrados:** $a^2 - b^2 = (a - b)(a + b)$.
- **Trinomio** $x^2 + bx + c$: busca dos números que multiplicados den $c$ y sumados den $b$.
- **Fórmula general:** $ax^2 + bx + c = 0 \Rightarrow x = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$.
- **Potencias:** $x^a x^b = x^{a+b}$, $\;\dfrac{x^a}{x^b} = x^{a-b}$, $\;\sqrt{x} = x^{1/2}$, $\;\dfrac{1}{x^n} = x^{-n}$.
- **Logaritmos:** $\ln(ab) = \ln a + \ln b$, $\;\ln(a^n) = n\ln a$, $\;\ln e = 1$, $\;\ln 1 = 0$.

### Dominio
- Fracción: el denominador **no** puede ser 0.
- Raíz cuadrada: lo de adentro debe ser $\geq 0$.
- Logaritmo: lo de adentro debe ser $> 0$.

### Composición e inversa
- $(f\circ g)(x) = f(g(x))$: primero se aplica $g$, después $f$.
- Para hallar $f^{-1}$: escribe $y = f(x)$, despeja $x$ y cambia los nombres de las variables.

### Recta
Pendiente $m = \dfrac{y_2 - y_1}{x_2 - x_1}$; ecuación punto-pendiente $y - y_0 = m(x - x_0)$.

### Errores comunes
- $(a + b)^2 \neq a^2 + b^2$. Lo correcto: $(a+b)^2 = a^2 + 2ab + b^2$.
- $\sqrt{a + b} \neq \sqrt{a} + \sqrt{b}$.
- Cancelar **términos** en vez de **factores**: $\dfrac{x + 2}{x} \neq 2$.
- Olvidar los paréntesis al evaluar: si $x = -3$, $x^2 = (-3)^2 = 9$, pero $-3^2 = -9$.
- Al dividir una desigualdad entre un número negativo hay que **invertir** el signo.
